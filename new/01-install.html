Software lifecycle for coding agents

Put a release bar on the agent

Agents skip spec, tests and a merge gate. One curl installs Waykit. wk runs the rest: TDD, a full PDLC and the loops after ship.

Single-line install · git and Node 22+

curl -fsSL https://raw.githubusercontent.com/mzworthington/waykit/main/install.sh | sh

Then: wk init . --mcp default --hook

What you get

Three jobs. Docs hold the rest.

  • High-quality code

    TDD short loop, then XFN. wk check is the merge bar: audit, ontology, evals, context budget.

  • Full PDLC and SDLC

    Grill, spec, TDD, quality, audit, release. Agents on every phase. Orchestrator stays in the parent chat.

  • Learning loops

    A miss becomes a failing eval. CI, RUM and scanners become Linear tickets the next session can play.

Evals sit on the merge gate

Same prompt, two outcomes. Without a case file you get a polite guess. With wk eval ci you get a failing assert. EDD is alpha: routing contracts, not a full eval platform.

wk eval ci --suite evals/edd/demo.yaml --threshold-routing 95
