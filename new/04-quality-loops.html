Software lifecycle for coding agents

High-quality code. Agents that learn.

One kit covers the full PDLC and SDLC. The left column is the bar. The right column is how the next session gets smarter. You run both with wk.

The bar

  • TDD: one failing test, then the smallest change.
  • XFN on UI, auth and SLOs: browser, a11y, security, load.
  • Hexagonal boundaries. Domain stays pure.
  • wk check before you mark a phase complete.

The loops

  • Eval: a miss becomes FAIL tool_selection, then a CI gate.
  • Quality loops: red checks, RUM, Lighthouse, Sonar → Linear.
  • Work picker plays allowlisted bugs as draft PRs.
  • EDD is alpha: routing contracts, not a full eval product.

Full agent-supported PDLC

Grill → spec → TDD → XFN → audit → ship. Specialists launch as host subagents. The orchestrator does not leave the parent chat.

Install, then the CLI

Single-line install

curl -fsSL https://raw.githubusercontent.com/mzworthington/waykit/main/install.sh | sh

Then wk init . --mcp default --hook. First week: wk, wk align ., wk check, wk eval ci.
