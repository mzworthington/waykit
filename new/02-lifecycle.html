One line, then wk

No API key. macOS and Linux.

Install

curl -fsSL https://raw.githubusercontent.com/mzworthington/waykit/main/install.sh | sh

Bootstrap a checkout with wk init . --mcp default --hook. Day to day: wk with no arguments.

The bar is in the loop, not a slogan

  • High-quality code

    Red, green, refactor in domain first. UI stays a delivery adapter. wk check fails a fat bootstrap and a broken ontology.

  • Evals

    wk eval ci gates routing. Alpha: tool contracts and prompts, not a general eval product. Same case file in CI and locally.

  • CLI

    wk align, wk doctor, wk check, wk eval ci. Scripts and the TTY menu share verbs.
