# Waykit map

Skills, host subagent stubs, SOPs, MCP servers, evals, and philosophy sections are derived from the kit tree, not a second catalog. Subagent nodes (`subagent:agent-tdd`) sit on an inner ring and `adapts` their playbook skill. The same index feeds kit-knowledge, so an agent can fetch one node instead of the whole kit.

Filter by type, search a name. The key on the graph names each node colour. Handovers stay off this public map; they are local-only. This is the kit’s own map, not a diagram of your product. To add a node, change a skill, stub, SOP, or eval and regenerate. Authoring: [Author the Waykit map](/ontology). Launch flow: [Host subagents](/docs/subagents).
