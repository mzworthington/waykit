# Waykit

The public homepage is the Astro landing in `web/` (hero, then docs destinations). This file is the copy source of truth for that story.

Waykit is the software lifecycle for coding agents: grill, PRD/bet when value is unproven, spec, TDD, quality, audit, release, plus learning loops. You operate it with `wk`. Eval-driven development (**alpha**) is one of those loops: a routing harness, not a full EDD product.

The homepage does not host the job picker, CLI table, kit map, product-repo grid, eval proof or interactive demo. Those live on the pages below.
